# Forward and Backward Chaining

Proyecto de inferencia mediante encadenamiento hacia adelante (*Forward Chaining*) y hacia atrás (*Backward Chaining*), con una base de conocimiento orientada a la identificación preliminar de enfermedades a partir de síntomas.

## 📄 Documentación

La documentación completa del proyecto se encuentra en la carpeta [`docs/`](./docs/).

Puedes consultar directamente el documento final en PDF:

**[📑 Ver documentación del proyecto](./docs/main.pdf)**

## 🧪 Casos de prueba

En [`archivos_resultados_pruebas/`](./archivos_resultados_pruebas/) se encuentran los archivos de texto con las trazas de ejecución de los cuatro casos de prueba utilizados para evaluar el sistema de inferencia.

## 📚 Fuentes de la base de conocimiento (KB)

La base de conocimiento se construyó con apoyo de herramientas de inteligencia artificial, de acuerdo con las instrucciones del proyecto, y posteriormente fue revisada utilizando fuentes de referencia.

Las fuentes consultadas, junto con sus respectivas descripciones, se encuentran en [`Fuentes KB.md`](./Fuentes%20KB.md).
